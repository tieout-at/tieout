## Regeln

- Neue Recherche nach `research_notes/`, Überholtes nach `archiv/`.
- Jede Aussage über die Welt braucht eine Quelle. Was im Dossier „(unbelegt)“ oder „(Annahme)“ ist, wird nicht als Tatsache weitergegeben.
- Abschnitt 12 im Dossier v3 ist entschieden. Nichts daraus wieder vorschlagen, außer mit neuer Evidenz.
