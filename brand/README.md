# Brand

Logo, colours and LinkedIn graphics for **tieout**. Everything is generated by script from SVG and rendered to PNG with headless Chrome, so it can be reproduced at any time.

## Basics

| | |
|---|---|
| Name | **tieout**, always lowercase, no trailing dot |
| Mark | two plan corners in ink, a square in ultramarine (`website/components/ui/Logo.tsx`) |
| Colours | paper `#F4F6F9`, ink `#0A1020`, ultramarine `#1D3BFF` |
| Typefaces | Inter Tight (text), IBM Plex Mono (labels) |
| Visual language | plan grid, dimension lines, line drawings |

Rules for the website: [`website/STRUKTUR.md`](../website/STRUKTUR.md).

## Folders

| Path | Contents |
|---|---|
| [`linkedin/upload/`](linkedin/upload/README.md) | **Final files** for LinkedIn: logo (pure white, 400 and 1200 px), company page cover (white, blue) |
| `linkedin/entwuerfe/` | Drafts: three banners for personal profiles (blueprint, electrical plan, twin), company page with and without sketch |
| `linkedin/erzeugen.py` | generates the three personal profile banners (1584 × 396) |
| `linkedin/firmenseite.py` | generates the company page covers (1128 × 191, double resolution) |
| `linkedin/export.py` | generates the upload files in `linkedin/upload/` |

## Regenerate

Requires Python 3 and Google Chrome.

```bash
python brand/linkedin/firmenseite.py
python brand/linkedin/export.py
```

The intermediate HTML files in `linkedin/entwuerfe/` are not tracked (`brand/.gitignore`).
