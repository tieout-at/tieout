# Schrittleiste

Where the Check stands: four fixed steps, completed ones with a check mark, the current one filled.

**Reference:** reebuild flow „Erfassen → Replizieren → Abgleichen → Kontrollieren und Freigeben“ (capture, replicate, reconcile, review and approve), Kuro „x von y“ (x of y).

**Usage**
- Below every step one line with figures. The last one counts „x von 12 Posten freigegeben“ (x of 12 items approved) (only stage 2 counts).
