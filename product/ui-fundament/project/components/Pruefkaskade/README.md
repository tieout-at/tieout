# Prüfkaskade

The final invoice (Schlussrechnung) from the GU's perspective, from the total value of work performed to the remaining amount due, every row with its base amount, source and contract comparison.

**Reference:** reebuild „Inhaltliche Prüfung“ (content review; groups discount / deductions reducing the work value / retentions with subtotals, base amount in parentheses, „laut Vertrag“ (per contract) in green, „Abweichung“ (deviation) in orange), BuildPass (cascade down to „zahlbar“ (payable)), Document Crunch („fehlt im Vertrag“ (missing from the contract) as a separate statement).

**Usage**
- Groups: deductions per the GU's deduction letter (Abzugsschreiben), retentions (Einbehalte), payments; each with a total.
- Below every row the base amount („auf die Summe nach Nachlass“, on the total after discount).
- Review only as fact: „laut Vertrag Pkt. x“ (per contract clause x) or „kein Vertragspunkt gefunden“ (no contract clause found). No statement on whether a deduction is permissible.
- The „Zahlungen“ (payments) row expands to show the individual interim invoices (Abschlagsrechnungen).
